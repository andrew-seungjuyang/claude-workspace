# claude-workspace

누리플렉스 가나 법인 업무를 Claude와 함께 처리하기 위한 작업 공간입니다.
법인 관리, 공장 운영, ECG 프로젝트 공급, 가나 내 영업(ECG, NEDCo 등), 아프리카 해외 영업에 쓰는 툴, 데이터, 문서를 한곳에서 관리합니다.

## 폴더 구조

| 폴더 | 용도 |
|---|---|
| `docs/` | 정리된 문서, 가이드, 참고 자료 |
| `notes/` | 회의 메모, 아이디어, 작업 기록 (`YYYY-MM-DD-주제.md`) |
| `scripts/` | 직접 만들어 배포하는 업무 툴과 스크립트 (툴마다 폴더 하나) |
| `data/` | 영업, 생산 등 작업에 쓰는 데이터 (민감 정보는 올리지 않음) |
| `outputs/` | 보고서, 제안서, 영업 자료 등 결과물 |

`docs/`, `data/`, `outputs/` 안에서는 업무 영역별 하위 폴더를 씁니다.

| 하위 폴더 | 업무 영역 |
|---|---|
| `entity/` | 가나 법인 관리 (행정, 본사 보고) |
| `factory/` | 공장 운영 (생산, 재고, 품질) |
| `ecg-project/` | ECG 프로젝트 공급과 납품 |
| `sales-ghana/` | ECG, NEDCo 등 가나 내 영업 |
| `sales-africa/` | 아프리카 해외 영업 (국가별 하위 폴더) |

## 사용 방법

1. Claude Code 세션에서 이 리포지토리를 선택하거나 연결합니다.
2. 원하는 작업을 요청하면 Claude가 [`CLAUDE.md`](CLAUDE.md)의 규칙에 따라 파일을 만들거나 수정합니다.
3. 변경 사항은 커밋해서 GitHub에 보관합니다.
