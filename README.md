# claude-workspace

Claude와 함께 작업하기 위한 개인 작업 공간입니다. 문서, 메모, 스크립트, 데이터와 작업 결과물을 한곳에서 관리합니다.

## 폴더 구조

| 폴더 | 용도 |
|---|---|
| `docs/` | 정리된 문서, 가이드, 참고 자료 |
| `notes/` | 회의 메모, 아이디어, 작업 기록 (`YYYY-MM-DD-주제.md`) |
| `scripts/` | 자동화 스크립트와 유틸리티 코드 |
| `data/` | 작업에 쓰는 입력 데이터 (민감 정보는 올리지 않음) |
| `outputs/` | Claude가 만든 보고서, 표, 문서 등 결과물 |

## 사용 방법

1. Claude Code 세션에서 이 리포지토리를 선택하거나 연결합니다.
2. 원하는 작업을 요청하면 Claude가 [`CLAUDE.md`](CLAUDE.md)의 규칙에 따라 파일을 만들거나 수정합니다.
3. 변경 사항은 커밋해서 GitHub에 보관합니다.
